# Clipboard Manager

A compact Windows clipboard history tool. It runs from the system tray and opens a searchable command bar with **Alt+V**.

## Download

Download the latest Clipboard Manager release from the [Releases page](https://github.com/MeheReal/clipboardmanager/releases/latest).

## Use it

1. Run ClipboardManager.exe. The app stays in the system tray.
2. Copy text as usual.
3. Press **Alt+V**, search your clipboard history, and press **Enter** to paste the selected item. Use the arrow keys to move through results and **Escape** to close the search bar.
4. Hover over a history item and click its **×** to delete that item.

Use the tray menu to open history, pause or resume clipboard capture, check for updates, or quit the app.

## Updates

Choose **Check for updates** from the tray menu. Clipboard Manager checks for a newer release and asks before downloading and installing it.

## Privacy

Clipboard history stays on this PC under the user's LocalAppData folder. Clipboard text is not uploaded to GitHub; GitHub is contacted only to check for app releases and download an update you approve.
